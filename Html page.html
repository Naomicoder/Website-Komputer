HTML

HTML merupakan sebuah markup language yang bertugas untuk mengatur tataan sebuah website. HTML menggunakan tags atau tanda dan diterjemahkan menjadi tataan website yang kita inginkan. Tags pada HTML ditandakan dengan simbol < > dan nama tag yang ingin digunakan ditulis di tengah-tengah simbol tersebut.

Awal Pembuatan File

Semua file HTML diawali dengan <html> dan diakhiri dengan </html>. Setelah <html>, kita harus membuat <head> </head> yang berguna untuk mencatat data mengenai file HTML tersebut. Data yang harus dimasukkan kedalam head HTML adalah title sebuah website, yang dituliskan di tengah <title> </title>. Title website akan menjadi judul dari tab HTML dan wajib dibuat. Selain itu, kita bisa menghubungkan file CSS dengan menggunakan tag link.

Heading dan Paragraph

Heading merupakan sebuah Judul bagian yang ingin ditampilkan dalam website tersebut. HTML memiliki 6 heading yang ditunjukkan dari tag <h1> sampai <h6>. Paragraph merupakan bagian text yang berisi penjalasan dan ditandakan menggunakan tag <p> </p>. Setiap paragraph baru selalu mulai pada garis yang baru dan disertakan sebuah margin. Jika ingin memisahkan satu paragraph tetapi masih menggunakan paragraph yang sama atau tidak ingin menunjukkan margin, maka kita harus membuat tag <br> di tengah kedua bagian tersebut. Heading dan paragraph dibuat di dalam <body> </body> yang terletak dibawah </head>.

Hyperlink

Hyperlink merupakan bagian dari text yang jika diclick akan membukakan website atau file yang baru. Hyperlinks menggunakan tag <a href=""> </a>. Link dari file atau website yang ingin kita buat menjadi hyperlink ditulis di tengah tanda kutip pada bagian href. Text yang dijadikan hyperlink ditulis sebelum </a>.

Video dan Gambar

Pada HTML, kita bisa menambahkan gambar dan juga video. Langkah pertama yang harus dilakukan adalah membuat file HTML dan file gambar atau video pada folder yang sama. Untuk menambahkan gambar, kita hanya perlu membuat tag img dan mencantumkan nama file pada bagian src. Untuk menambahkan video, kita harus membuat tag <video controls> </video> dan membuat <source src=""> di tengah tag video tersebut, sedangkan nama file ditaruh didalam tanda kutip pada bagian src.
